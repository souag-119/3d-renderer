# Render3D Studio — محرك رندر Path Tracing (نسخة محدّثة)

تطبيق ويب كامل لرندر مشاهد 3D بتقنية Path Tracing، يعمل بالكامل داخل المتصفح بدون أي تثبيت أو اتصال إنترنت.

## طريقة التشغيل

هذا التطبيق يحتاج تشغيله عبر خادم محلي (وليس فتح index.html مباشرة كملف):

### الطريقة 1: عبر Python
```
python3 -m http.server 8080
```
ثم افتح المتصفح على `http://localhost:8080`

### الطريقة 2: امتداد Live Server في VS Code
افتح المجلد في VS Code، ثبّت امتداد "Live Server"، ثم اضغط بزر الفأرة الأيمن على index.html واختر "Open with Live Server".

### الطريقة 3: أي استضافة استاتيكية
ارفع الملفات كما هي لأي استضافة (GitHub Pages، Netlify، Vercel) — لا حاجة لأي backend.

## المتطلبات
متصفح حديث يدعم **WebGL2** (Chrome، Edge، Firefox، Safari الحديثة)، ويُفضّل جهاز بمعالج رسومي (GPU) للأداء السلس.

## أهم ما تم تحديثه في هذا الإصدار

### الواجهة
- تصميم مبسّط تماماً بلا تأثيرات أو ظلال، بملء الشاشة بالكامل، بدون شريط علوي.
- زر ملء الشاشة مع محاولة قفل الاتجاه Landscape تلقائياً (يعتمد دعم المتصفح/الجهاز).
- زرا Undo / Redo عائمان لكل تعديل على المشهد.

### وضع العرض قبل الرندر
- عند فتح التطبيق، يظهر **عرض معاينة سريع (Rasterizer)** بإضاءة شمس أساسية وكاميرا تفاعلية — بدون بدء أي عملية Path Tracing تلقائياً.
- زر **"رندر"** واحد في أسفل الشاشة يبدأ الرندر الفعلي، ويعرض نسبة التقدم والعملية الجارية، ويتحول لزر **"إيقاف"** لإلغاء العملية في أي وقت.
- من تبويب "الرندر" يمكن تفعيل **وضع الرندر الحي (Realtime)**: عندها يقوم نفس الزر ببدء/إيقاف معاينة Path Tracing تراكمية حيّة بدل رندر لقطة نهائية واحدة.
- البلاطات (Tiles) تبدأ الآن من **مركز الإطار وتتوسع للأطراف** بدل الترتيب من أعلى لأسفل.

### التحكم باللمس والكاميرا
- إصبع واحد: تدوير الكاميرا (orbit)، أو تحريك عنصر Gizmo محدد.
- إصبعان: تكبير/تصغير (Pinch) + تحريك جانبي (Pan) في نفس الحركة.
- الاختيار الآن عبر **Raycasting حقيقي على كامل جسم العنصر** (وليس فقط نقطة مركزه)، مع تمييز العنصر المحدد بإطار أزرق (Outline) في وضع المعاينة.

### Gizmo
- حلقات التدوير أصبحت **مسطحة فعلياً على مستوى كل محور بالفضاء ثلاثي الأبعاد** بدل دوائر شاشة، لتفادي الالتباس البصري والاهتزاز.

### الكائنات والإضاءة
- **الكاميرا الآن عنصر في شجرة المشهد**: يمكن إضافة أكثر من كاميرا، ضبط إعداداتها (FOV، DOF، مسافة التركيز، فتحة العدسة)، ثم تفعيلها للعرض بزر "استخدام هذه الكاميرا" — مع تصميم بصري (هرم رؤية) يمثلها في المشهد.
- **إضاءة بقعة (Spot Light)** جديدة، بزاوية مخروط ونعومة حافة ومدى قابلة للتعديل، مع تصميم بصري لمخروط الضوء.
- إعدادات الإضاءة (اللون، الشدة، نعومة الظل) تظهر الآن في نفس مكان تبويب المتريال عند اختيار عنصر إضاءة.
- الإضاءة النقطية وإضاءة البقعة لديهما إعداد **Range** (مدى الضوء).
- تصميم بصري مميز لكل نوع إضاءة: خط اتجاه واضح للشمس، مخروط للبقعة، أشعة صغيرة حول الإضاءات النقطية والمساحية.

### المتريال
- **كرة معاينة حية** أعلى إعدادات المتريال تعرض النتيجة فوراً أثناء التعديل، قبل الضغط على "تطبيق".
- شريط **Smoothness** (تنعيم) بدل Roughness مباشرة (أكثر بداهة: كلما زاد → زاد لمعان السطح).
- **انكسار حقيقي** للضوء عبر المواد الشفافة (زجاج) حسب قيم IOR والشفافية (Transmission)، مبني داخل محرك Path Tracing نفسه (انعكاس/انكسار Fresnel تقريبي).
- شريط **نفوذ الضوء (Subsurface)**: يمنح المادة توهجاً داخلياً بلون مخصص عند سقوط الضوء من خلفها — مناسب لمحاكاة جلد الإنسان أو البلاستيك شبه الشفاف.

### الرندر
- **Bloom** قابل للتفعيل بقوة وحد سطوع (Threshold) قابلين للتعديل، يُطبَّق كـ post-process على النتيجة النهائية.
- زر لحفظ آخر رندر مكتمل كصورة PNG من تبويب الرندر مباشرة.

## ملاحظة على الأداء
الرندر يتم بالكامل عبر معالج جهازك الرسومي (GPU) داخل المتصفح. على الأجهزة الضعيفة أو بدون تسريع رسومي، قد تكون المعاينة الحية أو الرندر النهائي أبطأ — وهذا طبيعي ومتوقع لتقنية Path Tracing الحقيقية.
